[ MODULE : CRYPTO ] - Le Système Immunitaire & Le Coffre-Fort
================================================================================
Fonctions injectées dynamiquement si détectées dans le code source Lua.

  _crypto_hash(data, [algo="SHA256"])
    > Génère l'empreinte fractale d'une donnée. Métrique d'intégrité.
  _crypto_rng(min, max)
    > Générateur d'aléa cryptographique. Utilise le "Rejection Sampling" 
      pour garantir une distribution uniforme au bit près (zéro biais modulo).
  _crypto_seal(plaintext, key_string)
    > Scelle les données via AES-GCM (Confidentialité + Authenticité).
  _crypto_open(sealed_base64, key_string)
    > Ouvre le sceau. Échoue proprement si les données sont altérées.

[ EXEMPLE CRYPTO ]
--------------------------------------------------
function _init()

  local cle = "mot_de_passe_32_caracteres__"

[ MODULE : MATHX ] - La Géométrie du Réel Vivant
================================================================================
Outils pour la visualisation de données, les biomorphes et les transitions 
fluides, inspirés des métriques de récursivité structurelle.

  _mathx_lerp(a, b, t)
    > Interpolation linéaire. La transition fluide entre deux états (t: 0.0 à 1.0).
  _mathx_map(val, in_start, in_stop, out_start, out_stop)
    > Projection d'une valeur d'un espace fractal à un autre.
  _mathx_dist(x1, y1, x2, y2)
    > Distance euclidienne. Métrique de proximité structurelle.
  _mathx_noise(x)
    > Bruit de valeur 1D (inspiré de Perlin). Génère des variations organiques, 
      cohérentes et non répétitives, parfaites pour simuler des rythmes naturels.

[ EXEMPLE MATHX ]
--------------------------------------------------
local time_accum = 0

function _update()
  time_accum += 0.01
  
  -- Générer une valeur de "respiration" entre 0 et 1
  local raw_noise = _mathx_noise(time_accum) 
  
  -- Mapper cette respiration vers une plage de couleurs ou de tailles (ex: 10 à 50)
  local taille_vivante = _mathx_map(raw_noise, -1, 1, 10, 50)
  
  print("Rythme du systeme : " .. taille_vivante)
end

[ USAGE & TRANSFORMATION ]
================================================================================
  1. Ecrivez votre logique dans `mon_script.p8` (ou `.lua`)
  2. Transpilez :  python pico2ps.py mon_script.p8 -o mon_script.ps1
  3. Testez sans risque :  .\mon_script.ps1 -DryRun
  4. Exécutez en réel :    .\mon_script.ps1

  Le transpileur analysera l'AST, détectera l'usage de `_crypto_` ou `_mathx_`,
  et n'injectera que les modules nécessaires, gardant le code final léger et
  élégant. La concaténation Lua `..` est automatiquement aplatie en `+` PS.
